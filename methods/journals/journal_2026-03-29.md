### 5. Adaptation logic

```
diameter = max(tunnel_width, tunnel_height)
ratio = diameter / 5.5

if ratio > 1.05:
    scale SAM geometric params (K_height, AB_height, segment_width,
          y_bounds, prompt_points, template_mask) by ratio

if family == complex:
    segment_per_ring = 7
    segment_order = ["K", "B1", "A1", "A2", "A3", "A4", "B2"]
    n_segment_end = 6
```

## Key insights

1. **DIFY correctly adapted diameter-driven params** (unfolding, denoising) but **missed SAM geometric scaling and 7-class schema** for complex tunnels.
2. **Complex tunnels need 3 coordinated changes**: enhancing n_segment_end, SAM segment_per_ring/order, and SAM geometric scaling. Missing any one causes downstream failures.
3. **Regular tunnels close to sample diameter** (ratio ≤ 1.05) genuinely need no adaptation — the pipeline is calibrated for ~5.5m tunnels.
4. Running parameter adaptation directly in code is faster and more consistent than DIFY API calls for 150 files.
