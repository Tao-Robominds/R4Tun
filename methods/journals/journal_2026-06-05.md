## Summary

Proxy v2 trains three within-ring pairwise rankers (K / L / D) and combines them in
`proxy_cascade_full`. On held-out good-candidate rings (26 rings, oracle mIoU ≥
0.30 in pool), **cascade matches K-only exactly** (69% oracle-hit, 0.094 mean
regret, median rank 1). Deploy winner remains **`proxy_K_full`** — simpler and
equivalent on this panel.

Baselines `p11` / `rel_v2`: 0% oracle-hit, median rank 8–9 (ranking failure, not
reachability — see `methods/paper/trails/diagnostics/miss_analysis.md`).

## 1. Scoring formula (`proxy_cascade_full`)

Per candidate \(i\) in ring \(r\). Features are median-imputed, then axis-standardised
(\(\mathbf{z} = (\mathbf{x}-\boldsymbol{\mu})/\boldsymbol{\sigma}\)).

**K ranker** (7 features; pairwise logistic decision function):

\[
s^K_i = \mathbf{w}^K \cdot \mathbf{z}^K_i + b^K
\]

**Explicit anchor penalty:**

\[
d_i = \texttt{k\_anchor\_dist\_sam\_frac}_i \quad (\text{fill } 1.0 \text{ if missing})
\]
\[
\tilde{s}^K_i = s^K_i - d_i
\]

**L ranker** (10 form/seg features):

\[
s^L_i = \mathbf{w}^L \cdot \mathbf{z}^L_i + b^L
\]

**L gate** (\(\tau = 0.25\); L is always computed, gate controls whether it contributes):

\[
\text{plausible}_i = \mathbb{1}[d_i \le \tau]
\]

**D tie-break** (tiny nudge; not Stream-D branch selection):

\[
b_i = \arg\max\{\texttt{direction\_score\_plus}_i,\ \texttt{direction\_score\_minus}_i\}
\]
\[
\delta_i = 0.05 \times \texttt{direction\_score}_{b_i}
\]

**Cascade score:**

\[
S^{\text{cascade}}_i =
\begin{cases}
\tilde{s}^K_i + s^L_i + \delta_i & d_i \le \tau \\
\tilde{s}^K_i - 1.0 + \delta_i & d_i > \tau
\end{cases}
\]

**Selection:** \(\hat{i} = \arg\max_i S^{\text{cascade}}_i\) within ring.

**K-only deploy score** (`proxy_K_full`, winner):

\[
S^{K}_i = s^K_i - d_i
\]

(no L gate, no D tie-break)

## 2. Design rationale

### Why gate L (not continuous blend)?

Miss analysis on held-out (`good_form_wrong_anchor`): wrong-anchor perturbations
score **higher** on form metrics (`v5_balance_norm`, `v5_S_boundary`) than the
correct SAM baseline on `3-1-*` rings. Ungated `sk + sl` lets form override anchor
penalties. The gate encodes: *form evidence is valid only when anchor is plausible*;
outside the band, apply a hard veto (`−1.0`) rather than downweighting L smoothly.

K axis already uses **continuous** scoring (`−d_i`). L uses a **conditional** rule
(analogous to v3 failure memory: penalise high coverage when K confidence is low).

### Why D tie-break is 0.05 (tiny)?

Stream D (frozen L+K, twin plus/minus) can swing mIoU by **0.4–0.5** per ring
(e.g. `1-1/r20`: 0.69 vs 0.27; `5-6/r286`: minus 0.68 vs plus 0.16). That is
**post-detection branch selection** on one layout (`argmax(direction_score_*)` after
det), not 18-candidate ranking.

In the Stage-A pool each candidate has a **fixed** `order_branch`. Ranking chooses
among 18 `(layout, branch)` pairs; D's full lever is not available here. The 0.05
term only breaks near-ties among K+L-plausible candidates and is kept small so D
cannot override K (same lesson as gating L).

Canonical deploy path unchanged:

```
proxy K/L rank 18 candidates → det → proxy D (argmax) → seg
```

### Why cascade ≡ K on held-out

Once \(\tilde{s}^K_i - d_i\) separates anchor-close from far candidates, L and D
rarely change \(\arg\max\). Oracle and proxy_K picks sit at **median form rank ~7–9 /
18** — not top-form candidates. The deciding axis is K/anchor agreement, not form
regularity.

## 4. Training pools and features

- **Train:** calib v4 + contrastive stream K/L trials (`logs/proxy_discovery_v1/contrastive_trials.csv`, 1472 rows).
- **Objective:** within-ring pairwise logistic (not pooled mIoU Ridge).
- **Quarantined from rankers:** `param_hough_*`, segment-evenness (`seg_k_size_ratio`, `seg_block_size_variance_ratio`) — knob leakage / `good_form_wrong_anchor`.
- **K features:** `k_anchor_dist_sam_frac`, `k_anchor_dist_c0_frac`, `layout_k_center_norm`, `rho_K`, `rho_AB`, `line_detection_confidence_K`, `v5_S_K`.
- **L features:** coverage, arc entropy, reclass count, `v5_*` boundary/balance/spacing, `seg_groove_score`.

Models: `methods/paper/trails/proxies_v2/proxy_{K,L,joint}_ranker.json`.

## 5. Deploy recommendation

| Role | Model | Notes |
|---|---|---|
| **18-candidate ranking** | `proxy_K_full` | `s^K - d`; no cascade overhead |
| Form tie-break (optional) | `proxy_cascade_full` | Equivalent on current held-out panel |
| Branch selection (post-det) | `proxy_direction.json` | `argmax(direction_score_*)`; Stream D path |

**Caveats (honest):**

1. Held-out K distances were post-hoc enriched (`k_anchor_dist_*` from SAM prior /
   c0 baseline); Phase 1 pipeline logging exists but held-out pools not re-evaluated
   live yet.
2. 69% oracle-hit is full-fit eval (train calib+contrastive, score held-out), not
   strict LORO.
3. Re-run held-out candidate eval with live anchor/alignment features before paper
   claims.
