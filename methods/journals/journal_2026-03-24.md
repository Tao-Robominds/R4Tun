## Parameter archive vs [`agents/parameters/sample`](agents/parameters/sample) baseline

**Question:** Did any `agents/ablation/memory/parameters/<tunnel_id>/` **inference** (`*_m_opus4.6.json`) or archive (`parameters_*.json`) differ from the sample baseline (same five JSON files)?

**Check (2026-03-24):** For every subdirectory under [`agents/ablation/memory/parameters/`](agents/ablation/memory/parameters/) that contains `parameters_unfolding.json` (**30** dirs), SHA-256 of each of the five `parameters_<stage>.json` and five `parameters_<stage>_m_opus4.6.json` was compared to [`agents/parameters/sample/parameters_*.json`](agents/parameters/sample/).

| Result | Count | Detail |
|--------|-------|--------|
| Archive + `m_opus4.6` **identical** to sample (all 10 files) | **29** / 30 | Includes all **20** new-tunnel ids (`3-1-x`, `4-x`, `5-x`), **`1-1`–`1-5`**, **`2-1`**, **`2-3`–`2-5`**, **`1-4`**, etc. |
| Only **`2-2`** differs | 1 / 30 | **Trivial:** `diff` shows only a **final newline** on JSON files vs sample (no key/value change). |

**Spot check — unfolding `diameter` in `parameters_unfolding_m_opus4.6.json`:** `sample`, `3-1-1`, `4-1`, `5-1`, and `2-2` all report **`diameter`: 5.5**, **`delta`: 0.005** (same object content for those fields).

**Raw characteristics:** `sam4tun/plugins/raw_characteristics.py` previously injected a bogus constant **`actual_tunnel_diameter`: 5.5** into `tunnel_geometry` (misleading for LLM prompts). That field was **removed**; use **`estimated_diameter`** / **`diameter_estimation`** (MBR-based) only. Re-run raw characterisation to refresh on-disk `raw_characteristics.json` files.

**Interpretation:** In the repo state checked, **there is no evidence of per-tunnel LLM parameter edits** in the memory archive: values match **identity bootstrap** (copy sample → archive → `*_m_opus4.6` → `agents/<id>/`). That matches a workflow that ran **E2E with a shared baseline**, not a fresh Opus inference pass per tunnel. If tunnels truly differ in ring geometry in the field, you would still need to **run analysts + replace `*_m_opus4.6.json`** (and re-sync executables) so JSON on disk reflects those differences; the current files do not.
