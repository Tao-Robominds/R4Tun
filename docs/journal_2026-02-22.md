# Daily Journal — 22 February 2026

## Objective

Investigate GT coverage for regular agent preprocessing outputs (1-4, 2-2, 3-1) and test whether adding `double_zero_cutoff` and `smoothing_offset` parameters (as used in irregular/complex agents) can improve coverage to 100%.

---

## Context & Starting Point

| Metric | Value | Notes |
|--------|-------|-------|
| Regular agent coverage (1-4) | 98.16% | 939,598 / 957,258 GT-block points mapped |
| Regular agent coverage (2-2) | 97.79% | 1,213,284 / 1,240,703 GT-block points mapped |
| Regular agent coverage (3-1) | 99.71% | 2,234,636 / 2,241,034 GT-block points mapped |
| Irregular agent coverage | 100% | Uses `double_zero_cutoff=false, smoothing_offset=0.0` |

**Background:** The irregular/complex agents use GT-optimal denoising parameters (`double_zero_cutoff=false, smoothing_offset=0.0`) that achieve 100% GT-block coverage. The regular agent's preprocessing script hardcodes these values (`double_zero_cutoff` always ON, `smoothing_offset=-0.003`), potentially causing the 1-3% coverage gap.

---

## Experiments & Results (chronological)

### 1. GT Coverage Check for Regular Agents

**Result:** Current GT-block coverage in `enhanced.csv` and `pixel_to_point.pkl`:
- **1-4:** 98.16% (939,598 / 957,258 GT-block points mapped)
- **2-2:** 97.79% (1,213,284 / 1,240,703 GT-block points mapped)
- **3-1:** 99.71% (2,234,636 / 2,241,034 GT-block points mapped)

All retained GT-block points (pred != 0) are successfully mapped; coverage loss occurs during denoising.

### 2. Coverage Fix Experiment (Reverted)

**Test:** Added `double_zero_cutoff=false, smoothing_offset=0.0` parameters (matching irregular agents) to improve coverage.

**Result:** Coverage improved slightly (+0.95-1.02% for 1-4, 2-2), but depth map dimensions changed dramatically for 2-2 (-47% width/height), breaking downstream stages (mIoU dropped from 0.911 to 0.227). **Experiment reverted** — small coverage gain not worth the performance degradation.

## Key Insights

1. **Regular agent coverage is already good.** At 97.79-99.71%, the remaining 1-3% gap is acceptable given downstream stability.

2. **Coverage fix parameters cause dimension instability.** Adding `double_zero_cutoff=false, smoothing_offset=0.0` improved coverage slightly but caused dramatic dimension changes (2-2: -47% width/height), breaking SAM (mIoU 0.911 → 0.227). Small coverage gain not worth the risk.
