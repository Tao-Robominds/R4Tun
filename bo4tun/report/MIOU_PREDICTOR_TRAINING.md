# mIoU Predictor Training Report

_Last updated: February 2, 2026_

This document summarizes how the current no-ground-truth (No-GT) mIoU predictors were trained, what data was used, the resulting model quality, and the remaining gaps that require additional data collection.

---

## 1. Objective

- Predict final mIoU for each tunnel pattern _without ground truth_ by relying solely on intrinsic metrics generated by the pipeline.
- Provide two use cases:
  - **Guardrails:** catch obvious failures early.
  - **Bayesian Optimization ranking:** prioritize promising configurations when ground-truth mIoU is unavailable.

We trained separate models for **simple patterns (1-4, 2-2, 3-1)** and **complex patterns (4-1, 5-1)** because their intrinsic metrics behave differently.

---

## 2. Data Sources

| Dataset | Description | Samples | Notes |
|---------|-------------|---------|-------|
| `bo4tun/training/comprehensive_all_metrics.csv` | Intrinsic metrics (preprocessing, detection, SAM, complex SAM) for existing 12 experiments | 12 | Only source with full `det_*` and `sam_*` metrics |
| `bo4tun/training/detection_only_metrics.csv` | 50 detection-only runs | 50 | Useful for guardrail exploration, not used for predictor training because SAM metrics missing |

> **Key limitation:** only **8 simple** and **4 complex** samples contained both detection and SAM metrics. Attempts to generate more metrics by re-running detection + SAM were blocked by parameter-loading issues (the scripts prefer `p4tun/parameters/<tunnel_id>/<...>.json` and expect nested JSON structures). We paused after confirming the fix but lack the runtime to regenerate all 20 planned configurations.

---

## 3. Feature Selection

Based on earlier ablation studies and Spearman analysis we kept only metrics that were both interpretable and showed consistent correlation.

### Simple Patterns

| Feature | Stage | Interpretation |
|---------|-------|----------------|
| `det_midpoint_ratio` | Detection | Fraction of K-blocks found via midpoint intersections |
| `det_real_detection_ratio` | Detection | Ratio of algorithm-detected vs assumed blocks |
| `det_x_spacing_cv` | Detection | Coefficient of variation of horizontal spacing |
| `det_y_std` | Detection | Vertical jitter among detections |
| `sam_mask_fill_rate` | SAM | Fraction of tunnel area covered by SAM mask |

### Complex Patterns

All features come from complex SAM metrics (ring-level coverage/consistency).

| Feature | Description |
|---------|-------------|
| `complex_sam_ring_completeness` | Fraction of rings with >50% coverage |
| `complex_sam_segment_height_cv` | Height uniformity |
| `complex_sam_segment_width_cv` | Width uniformity |
| `complex_sam_segment_area_cv` | Area uniformity |
| `complex_sam_ring_coverage_cv` | Cross-ring consistency |
| `complex_sam_aspect_ratio_mean` | Average geometry conformity |

---

## 4. Training Procedure

- **Model:** Ridge regression (α=1.0).
- **Targets:** measured mIoU from the limited ground-truth set.
- **Validation:** leave-one-out cross-validation (LOO) due to extremely small sample size.
- **Implementation:** `bo4tun/train_miou_predictors.py`, models saved under `bo4tun/models/`.

### Data Preparation Steps
1. Load `comprehensive_all_metrics.csv`.
2. Split by pattern type.
3. Drop rows with missing required metrics.
4. Normalize implicitly through Ridge (no additional scaling since metrics already bounded).
5. Train and serialize models into `simple_miou_predictor.pkl` and `complex_miou_predictor.pkl`.

---

## 5. Results

| Model | Samples | In-sample MAE | In-sample Spearman | LOO MAE | LOO Spearman | Interpretation |
|-------|---------|---------------|--------------------|---------|--------------|----------------|
| Simple | 8 | 0.041 | 0.50 | 0.067 | 0.12 | Moderately accurate in-sample, weak generalization (needs more data) |
| Complex | 4 | 0.096 | 0.80 | 0.175 | -0.80 | Strong overfitting due to only 4 samples |

### Usage Accuracy (current dataset)

- **Simple:** average absolute error 0.041 (≈4% mIoU). LOO Spearman 0.12 → only slightly better than random ranking.
- **Complex:** average absolute error 0.096 (≈10% mIoU). LOO Spearman negative → unreliable ranking.

## 6. How to Use the Models

### Option A – via helper module
```python
from bo4tun.miou_predictor import predict_miou

result = predict_miou(
    tunnel_id='2-2',
    detected_csv='data/2-2/detected.csv',
    final_csv='data/2-2/final.csv'
)
print(result['predicted_mIoU'])
```

### Option B – direct access
```python
import pickle
from bo4tun.intrinsic_metrics import compute_detection_metrics, compute_sam_metrics

det = compute_detection_metrics('2-2', 'data/2-2/detected.csv')
sam = compute_sam_metrics('2-2', 'data/2-2/final.csv')

with open('bo4tun/models/simple_miou_predictor.pkl', 'rb') as f:
    data = pickle.load(f)

features = [det['midpoint_ratio'], det['real_detection_ratio'],
            det['x_spacing_cv'], sam['mask_fill_rate'], det['y_std']]
prediction = data['model'].predict([features])[0]
```

## 7. Outstanding Work

1. **Collect additional intrinsic metrics:** at least 30 samples per pattern type to stabilize correlations.
   - Fix parameter loading (`p4tun/parameters/<tunnel>/parameters_detection.json`) using nested JSON structure (`preprocessing.binary_threshold`, etc.).
   - Re-run detection + SAM for the 20 prioritized configs (`bo4tun/training/configs_to_run.csv`).
2. **Extend feature set once data increases:** re-run comprehensive ablation to confirm which detection/SAM metrics remain predictive.
3. **Introduce uncertainty estimates:** bootstrap or Bayesian Ridge to provide confidence intervals for BO guardrails.
4. **Document guardrail thresholds:** integrate predictor output with existing guardrail rules (`det_midpoint_ratio < 0.3`, `sam_mask_fill_rate < 0.45`, etc.).

---

## 8. Key Takeaways

- The current models **must not** be treated as accurate mIoU predictors—they are early prototypes meant to rank/guard, not replace evaluations.
- Intrinsic metrics remain the right approach; the limiting factor is data volume, not methodology.
- Focus should now shift to automation of intrinsic metric collection so we can re-train with statistically meaningful sample sizes.
