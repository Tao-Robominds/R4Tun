## Reasoning for Tunnels

R4Tun: a reasoning-based multi-agent framework for segmental tunnel analysis in point clouds.

Automated inspection of segmental tunnel linings is vital for structural health assessment and long-term operational safety. Modern laser scanning produces large point-cloud datasets of linear infrastructure with highly repetitive lining patterns, but reliably segmenting these into individual components remains a challenging step for downstream deformation analysis and defect localisation. Current pipelines depend heavily on expert-driven hard-coded features, annotated datasets, or specifically tuned parameters,  undermining their suitability for field deployment at scale. This paper presents R4Tun, a reasoning-based multi-agent framework that wraps an existing expert-designed segmentation pipeline with constrained large language models (LLMs) driven reasoning layers for context-aware parameter adaptation. Evaluated on the open-source Seg2Tunnel benchmark under controlled deviation from an expert-tuned reference, R4Tun improves average mIoU from 28.5\% to 44.8\% (+57% relative), and in off-reference cases prevents baseline collapse from average mIoU 3.8\% to 34.9\% (+818% relative). The results show that R4Tun exhibits greater robustness by adapting parameters explicitly, as tunnels drift from the expert-tuned reference conditions. The proposed reasoning-based framework demonstrates the potential of multi-agent AI systems to act as transparent, engineer-guided systems, supporting scalable and deployable automation for tunnel lining inspection. 


# Dataset Description

The data shared on [Google Drive](https://drive.google.com/drive/folders/1riv1kZT-hC3eM-LoqiLTMrQqkTcoQ_j7?usp=drive_link) represents a comprehensive experimental dataset documenting the systematic evolution of the R4Tun tunnel 3D point cloud segmentation pipeline through six distinct ablation study configurations. Beginning with the original SAM4Tun baseline results in `1.original/`, `2.baseline/` establishes the foundational ablation framework, `3.point_context/` introduces point cloud contextual analysis, `4.point_context+CoT+Knowledge/` integrates Chain-of-Thought reasoning with domain knowledge, `5.image_CoT+Knowledge/` applies image-based cognitive reasoning, and `6.self-reflection/` implements autonomous self-reflective optimisation. Each configuration processes five distinct tunnel datasets (`1-4`, `2-2`, `3-1`, `4-1`, `5-1`) through the complete pipeline stages (unfolding, denoising, enhancing, and prompting). Comprehensive outputs include processed point clouds (CSV files), depth map visualisations, algorithm characteristics (JSON), analytical reports (Markdown), code modifications (Python), and performance evaluations with OA, F1 and IoU metrics.
